### Core Technical Competencies 
My technical strengths span several critical domains of computer science:
•	Software Engineering: I am proficient in designing applications that strictly adhere to modern architectural patterns, such as the Model-View-ViewModel (MVVM) and Model-View-Controller (MVC) frameworks. Before writing code, I value the planning phase, drafting comprehensive structural architecture documentation and component diagrams to ensure a clear vision that results in decoupled, scalable, and testable applications.
•	Algorithms & Data Structures: Grounded in principles from Data Structures and Algorithms (CS 300), I have developed the analytical skills necessary to evaluate time and space complexity, allowing me to implement optimized structures like hash maps that drastically reduce data retrieval times.
•	Database Management: My expertise extends to full-stack integration. Outside of my portfolio artifacts, I demonstrated this in Full Stack Development I (CS 465) by developing the Travlr Getaways web application, where I integrated a live NoSQL database layer, designed structural architecture, and executed database seeding scripts via Mongoose.
•	Security by Design: Underpinning all these domains is a steadfast commitment to security. My approach requires proactively mitigating vulnerabilities. Drawing on my experience in Secure Coding (CS 405) and Software Security (CS 305), I have configured manual validation layers to block buffer overflows, set up Google Test fixtures to catch SQL injection tautologies, and implemented strict Regex input validation to protect backend layers from adversarial exploits.
