Professional Self-Assessment

As I conclude my Bachelor of Science in Computer Science at Southern New Hampshire University, I am preparing to transition into the software engineering workforce with a specialized focus on secure full-stack development. Throughout this program, I have cultivated a robust technical skill set that bridges the gap between intuitive front-end design and highly scalable, secure backend systems. Developing this ePortfolio has provided an invaluable opportunity to synthesize my academic journey, shape my professional values, and quantitatively demonstrate my capability to deliver production-ready software. By revisiting and enhancing my legacy projects, I have been able to showcase my growth from a foundational programmer into a methodical software engineer who prioritizes security, efficiency, and architectural integrity.

Collaborative Engineering & Professional Ethos

My coursework extended beyond writing syntax; it actively prepared me for the collaborative and planning realities of the tech industry. In courses like Software Development Lifecycle (CS 250) and System Analysis and Design (CS 255), I learned the necessity of working within structured development environments, utilizing version control to manage branches and execute rigorous code reviews. I also developed the ability to effectively communicate with stakeholders. By drafting comprehensive project proposals, such as outlining the geometric layout for a 3D desktop workstation scene in Computer Graphics and Visualization (CS 330) and designing multi-screen digital wireframes for a food scanner application in UI/UX Design and Development (CS 319), I learned how to translate complex technical concepts and architectural trade-offs into clear, logical roadmaps for diverse audiences. These experiences have shaped my professional ethos: I believe that writing secure, efficient code is only half the job, as the other half is communicating its value and maintaining it systematically.

Core Technical Competencies

My technical strengths span several critical domains of computer science:

  • Software Engineering: I am proficient in designing applications that strictly adhere to modern architectural patterns, such as the Model-View-ViewModel (MVVM) and Model-View-Controller (MVC) frameworks. Before writing code, I value the planning phase, drafting comprehensive structural architecture documentation and component diagrams to ensure a clear vision that results in decoupled, scalable, and testable applications.
  • Algorithms & Data Structures: Grounded in principles from Data Structures and Algorithms (CS 300), I have developed the analytical skills necessary to evaluate time and space complexity, allowing me to implement optimized structures like hash maps that drastically reduce data retrieval times.
  • Database Management: My expertise extends to full-stack integration. Outside of my portfolio artifacts, I demonstrated this in Full Stack Development I (CS 465) by developing the Travlr Getaways web application, where I integrated a live NoSQL database layer, designed structural architecture, and executed database seeding scripts via Mongoose.
  • Security by Design: A steadfast commitment to security underpins my entire technical approach. I prioritize proactively mitigating vulnerabilities, drawing on my experience in Secure Coding (CS 405) and Software Security (CS 305) to build robust defenses. My practical experience includes configuring manual validation layers to block buffer overflows, deploying Google Test fixtures to catch SQL injection tautologies, and implementing strict Regex input validation to protect backend layers from adversarial exploits.

ePortfolio Artifacts

The artifacts included in this ePortfolio were carefully selected from my coursework and enhanced to represent this comprehensive skill set.

  • Software Design and Engineering: The first artifact is an Android Inventory Tracking Application originating from Mobile Architecture & Programming (CS 360). Originally a legacy codebase, I refactored it to enforce the MVVM architectural pattern and implemented strict input validation. This artifact demonstrates my ability to decouple UI logic from database operations and proactively secure data pipelines.
  • Algorithms and Data Structures: The second artifact is a C++ Investment Portal Application rooted in Software Reverse Engineering (CS 410). I migrated its legacy linear search functions to an optimized hash map and refactored the memory management to utilize smart pointers. This artifact showcases my capacity to maximize algorithmic efficiency while natively enforcing memory safety.
  • Databases: The final artifact is a Client/Server Dashboard utilizing MongoDB from Client/Server Development (CS 340). I enhanced this artifact by implementing native JSON schema validators and compound database indexing. This piece illustrates my proficiency in NoSQL database administration, focusing on data integrity and high-performance retrieval.

Together, these artifacts work to form a holistic picture of my abilities as a full-stack software engineer. They demonstrate that I can architect the frontend, optimize the processing logic in the middle, and rigorously secure the backend database. I invite you to review these projects as a demonstration of my readiness to tackle complex, real-world software engineering challenges.
